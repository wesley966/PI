## Breve explicação sobre a relação de cada referência com o PI
- Scratch: referência em ensino de programação para iniciantes utilizando blocos visuais.
- CodeCombat: referência em aprendizagem baseada em jogos com uso de código real.
- Blockly Games: referência na introdução gradual de conceitos de lógica computacional.
- Lightbot: referência no desenvolvimento do pensamento algorítmico.
- Minecraft Education: referência no uso de ambientes imersivos para aprendizagem.
- Roblox Studio: referência na aplicação prática da programação através da criação de jogos.
- Seu App: proposta que integra gamificação e programação textual para o ensino de adolescentes.
